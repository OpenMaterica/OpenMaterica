# Build-check cases: what each case file tests

One row per file in `cases/`, grouped by case id; each heading quotes the case's row in
`docs/specification/declarations.md`, which holds where the two differ. **Decided by** names the text of
`declarations.md` (or `record_format.md`, `read_side_contract.md`, `provenance.md`) that decides the answer.
**Expected** is read from the case file: the refusals the build gives the declaration checked on its own, each the
case id of the rule broken and the JSON pointer into the declaration (`""` is the empty pointer, the declaration
itself); for a declaration that passes, each result in brackets (its model, the record read by `id`, and the field;
its status and reasons, any other member it compares, whether it is accepted, the 0-based indexes of the
acceptances in `accepted_by`, and what is not accepted), the members of each result compared, and the acceptances
unused, by model and index; then the report's members that must be absent (a refused declaration gives no results,
no watches and nothing unused), the rules whose refusals the case compares where it names any, and the claims the
case states. See `README.md` beside this file for the fixtures and what the cases cannot show.
